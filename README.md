# 🏠 Riesenhaus mit Alien-Garage 👽

Ein kleines, verspieltes Projekt: ein **brutal großes, cooles Haus** im LEGO-Duplo-Look,
mit einem Platz, wo **Autos parken**, und einer **unheimlichen Garage, aus der Aliens
rauslugen**. Inspiriert von einer echten Duplo-Spielszene. 🧱

Es gibt **zwei Teile**:

## 1. 🧱 In echt nachbauen → [`BAUANLEITUNG.md`](./BAUANLEITUNG.md)
Eine kinderfreundliche **Schritt-für-Schritt-Anleitung**, um das Ganze mit euren
echten Duplo-Steinen zu bauen: Haus, Garage, Aliens und einparkende Autos. Mit
Steinliste und Skizzen. Zum Vorlesen und gemeinsam Bauen gemacht.

## 2. 🖥️ Digitale Vorschau (im Browser) → `index.html`
Eine bunte, interaktive Szene als Referenzbild:

- **Öffnen:** Doppelklick auf `index.html` (oder im Browser öffnen). Kein Internet,
  kein Installieren, keine Extras nötig.
- **Was geht:**
  - 🚗 **Auto vorfahren** – ein Auto fährt vor und parkt ein.
  - 🚪 **Garage auf/zu** – oder direkt die Garage anklicken → Aliens lugen raus.
  - 👽 **Alien anklicken** → es duckt sich weg.
  - 🛸 **UFO rufen** – ein UFO schwebt über die Szene.
  - Die Szene lebt auch von selbst: Wolken ziehen, Alien-Augen blinzeln.

### Dateien
| Datei | Inhalt |
|---|---|
| `BAUANLEITUNG.md` | Echte Duplo-Bauanleitung zum Nachbauen |
| `index.html` | Struktur der digitalen Szene |
| `styles.css` | Duplo-Look (Steine mit Noppen) + Animationen |
| `main.js` | Interaktivität (Klicks, Autos, Garage, UFO) |

Reines HTML/CSS/JS — keine Frameworks, keine externen Assets, läuft offline. 💚
